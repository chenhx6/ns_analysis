`run.sh` 当前保存了旧命令和串行循环，属于待适配的底本。它承担调度层设计：将 `runA0–runAn` 拆为独立任务、限制后台进程数量并等待全部任务结束。并行调度还需考虑内存、磁盘吞吐、逐任务日志与输出文件独占。

依据 `main.cc` 和 `UserDefine.hh`，当前两个参数是 Crate0/Crate1 的 run 编号；依据 `r2root.cc`，输出名逐项包含各 crate 的 run 编号。批量区间应由脚本展开，不能把两个 crate 参数当成解码起止编号。此用途记录不表示底本已经改造成可直接运行的并发调度器。
