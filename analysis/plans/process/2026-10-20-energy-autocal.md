## 目标与范围

制作可编译的 C++/ROOT 自动能量刻度程序，供当前 run 6082 和以后实验重复使用。默认发现并尝试拟合文件中的全部通道；用户可显式排除拟合，拟合完成后再决定是否采纳各通道系数。输出拟合参数、拟合报告、逐通道 PNG 回查图及包含直方图和拟合对象的 ROOT 文件。

本轮仅形成讨论稿。未来程序首先处理单个解码 ROOT 文件，不默认增加多 run 合并、能量漂移修正、效率刻度、addback 或 gamma-gamma 符合矩阵制作。今后复用以源种类、能量覆盖和输入格式满足条件为前提，不承诺任意谱都能自动成功。

## 已确定的配置要求

正式配置放在独立的 `autocal/UserDefine.hh`，采用有类型的 C++ 常量和列表；修改后重新编译。以下为建议接口示例，尚未创建程序：

```cpp
const std::string InputFile = "decode_data/data_C1_6082_notwave.root";
const std::string OutputDir = "calibration/energy/";
const std::vector<std::string> Sources = {"152Eu", "133Ba"};
const std::vector<Channel> ExcludedFitChannels = {}; // Channel 使用 cid、sid、ch 三个整数。
// 例如 {{0, 2, 4}} 仅排除这一通道的拟合，不删除该通道原始谱。
```

- 相对路径统一相对项目根目录解析；从其他目录启动时行为须一致。明确如何定位项目根，并支持绝对路径，不依赖运行时碰巧处于源码目录。
- 自动发现通道；ROOT 对象采用唯一名称，如 `cid0_sid2_ch4`。排除配置使用硬件三元组，避免字符串拼写不一致；配置指定不存在通道时给出提示。
- 源名称必须精确匹配源库，未知名称、重复源、损坏数据应在拟合前明确报错，不静默忽略。
- 源库建议采用一个有表头的 `sources.csv`，字段为源名、能量 keV、能量不确定度 keV、发射概率及其单位、是否候选使用、数据出处和版本。缺失项明确缺失；具体数据从可靠评估数据核验后填写，本讨论稿不凭记忆编造精确能量或误差。
- 源强度仅辅助识别；探测效率、吸收、符合相加和几何条件会改变峰高，不能硬性要求实验峰高比例等于发射概率。
- 低层参数集中且有单位注释：道址范围与分箱、寻峰参数、局部拟合范围、线性模型、质量条件；数值在样谱核查后确定，不堆叠尚无用途的开关。

## 建议的方法与统计处理（未确认项不作为既定方法）

### 逐通道填谱与筛选

以每条解码记录为填谱单位，以 `(cid,sid,ch)` 为刻度单位；不使用时间符合筛选。默认全部通道填原始谱，包括用户排除拟合的通道。

建议保留未筛选原始谱和实际用于拟合的质量筛选谱。拟合谱是否剔除 `pileup`、`outofr` 标记待确认；同时记录各类剔除计数。无标记、零值、饱和值和异常标记的具体处理需核对输入定义，不能未经记录删条目。

`evte` 完整整数取值范围为 0–65535。建议原始谱每整数道址一箱；寻峰可临时重分箱或平滑，但精细拟合回到未平滑计数谱，避免把平滑后相关计数当独立 Poisson 计数。

### 寻峰与自动匹配

候选峰搜索、粗刻度匹配、局部拟合和最终刻度分开处理。建议先找候选峰，再按能量顺序和多条参考线的整体一致性搜索正斜率线性映射，不能仅按最高峰一对一匹配。增益与截距的合理搜索范围待由当前谱与电子学条件确定。

保留竞争匹配的得分和歧义；缺峰、噪声峰、合峰、参考能量超出有效范围都允许存在。无法唯一确定映射时标记待复核，不强行输出可用系数。建议提供可选的每通道两点锚定入口，供全自动失败后恢复，是否需要此入口待确认。

自动拟合并不要求每条源谱线都形成独立可辨峰。尤其 LaBr₃ 的相邻线可能合并，不能把合峰峰心直接绑定到其中一条线；只有可辨且匹配可靠的峰用于刻度，必要的联合峰拟合须有可辨识性检查。首版不默认增加复杂闪烁体非正比响应模型。

### 局部峰拟合

建议基本模型为 Gaussian 峰加局部线性本底，对未平滑计数使用分箱 Poisson 似然；峰宽、面积等有物理约束。相邻可辨峰可做多峰联合拟合，明显偏离基本峰形的谱段标记待复核。是否加入低能拖尾，仅在残差证据支持时讨论。

每个尝试拟合的峰输出源名、参考能量、峰心及误差、FWHM、面积、拟合窗口、拟合状态、协方差质量和采纳理由。弱峰误差不稳定或峰高度相关时不得仅因 minimizer 收敛就判成功；不将峰宽当峰心误差。

### 能量刻度与验证

建议首版采用线性刻度：

\[
E\;(\mathrm{keV})=a+bA,\qquad b>0,
\]

其中 A 为原始道址，a 的单位为 keV，b 的单位为 keV/道址。拟合应传播峰心统计误差，参考能量误差有据时纳入；例如有效方差为 \(\sigma_{E_i}^2=\sigma_{\mathrm{ref},i}^2+b^2\sigma_{A_i}^2\)，多峰联合拟合产生的相关性需保留或明确处理限制。

报告 a、b、不确定度、协方差、采用点数、参考能量覆盖范围、逐点残差和拟合优度。建议至少 4 条可靠且能量分布充分的峰才自动推荐，但数量、能量跨度和残差阈值均待讨论并用数据验证；两点精确连线本身不能证明刻度正确。

建议做留一峰检验；匹配阶段已经使用的线不称为独立验证线。只有确实未参与匹配、调参及拟合的参考线才可称独立验证。系统性的残差趋势用于判断线性模型不足，不能无记录地删点直至通过。

最终输出分别记录程序质量状态与用户采纳决定，例如 `quality_status` 和 `adopted`。未知、不稳定、歧义或外推范围必须明确；不自动将失败通道系数设为 0 或套用邻道系数。二次项与可接受残差的具体 keV 阈值待确认，不预设所有探测器采用相同峰宽或误差门槛。

本任务的计数拟合不涉及组间显著性比较，多重比较校正不作为刻度误差的替代。搜索大量候选映射造成的错配风险通过匹配歧义检查和回查处理。

## 验证与完成标准

- 无排除配置时，当前输入应有 39 路拟合尝试记录；同一通道不得因树周期重复填谱。sid=8 必须在输出中。
- 原始谱总计数与选定树条目数一致，拟合谱剔除量可追溯；所有未纳入条目有定义和计数，包含上下溢出。
- 空排除列表与非空三元组排除均可验证；排除拟合仍保留该通道直方图、报告行和状态。
- 常用源数据带出处及版本；错拼源名、缺文件、分支类型异常、重复输出均明确报错。
- 保存一个最小可运行的验收程序，检查已知参数的测试谱、缺峰／干扰峰／近邻合峰和歧义匹配。测试谱显式标为模拟，不与实验结果混用。
- 实验峰心、系数、残差可从输出对象重算；失败通道不输出伪成功。采用阈值的数值在实施前固定并记录，物理成功率由真实结果决定。
- ROOT 可重新打开，每个通道的对象名、原始谱、拟合结果与 CSV 一致；系数的顺序、单位和适用能量范围明确。
- PNG 含可辨文字、单位和拟合标识；实际检查最终渲染，确认无裁切、堆叠或误标。全部通道文件存在不等于已完成图像审查。
- 重跑相同输入与配置得到一致的数值结果；修改输入配置后不误用旧系数。不要求 ROOT/PNG 文件逐字节相同。
- 报告如实给出成功、失败、排除和待复核数量，不预设全通道通过。验证与交付只收本任务范围。
