## 目标与范围

程序不依赖探测器类型信息，只按 (cid,sid,ch) 处理，可移植到其他实验。主要刻度对象是 HPGe / Clover 探测器，LaBr3 等非 HPGe 探测器尝试拟合但不作为主要目标。

## 方法与统计处理

### 逐通道填谱

以每条解码记录为填谱单位，以 `(cid,sid,ch)` 为刻度单位；不使用时间符合筛选。只读取 cid、sid、ch、evte 四个分支，不对 pileup / outofr 做任何筛选。默认全部通道填谱，包括用户排除拟合的通道。

`evte` 完整整数取值范围为 0-65535。建议原始谱每整数道址一箱；寻峰可临时重分箱或平滑，但精细拟合回到未平滑计数谱。

峰的光滑程度与 bin 宽度密切相关。寻峰和峰形处理逻辑集中在一个 `.hh/.cc` 文件中（面向对象），负责：从直方图或数组中寻找可拟合的峰候选，提供合适的初始参数，判定峰拟合是否成功。

### 寻峰与自动匹配

候选峰搜索、粗刻度匹配、局部拟合和最终刻度分开处理。先用 ROOT 的 TSpectrum 寻峰，再按能量顺序和多条参考线的整体一致性搜索正斜率线性映射。参考网页方法：先由两个相距较远、指认可靠的强峰建立粗略线性关系，再据此定位其余参考线。增益与截距的合理搜索范围待由当前谱与电子学条件确定。

保留竞争匹配的歧义；缺峰、噪声峰、合峰、参考能量超出有效范围都允许存在。无法唯一确定映射时标记失败，不强行输出可用系数。首版不实现手动锚定，匹配失败的通道直接标记失败。

自动拟合不要求每条源谱线都形成独立可辨峰。LaBr3 的相邻线可能合并，只有可辨且匹配可靠的峰用于刻度。

### 局部峰拟合

基本模型为 Gaussian + pol1（线性本底），即 f(x) = H*exp(-(x-mu)^2/(2*sigma^2)) + b0 + b1*(x-x0)。按参考网页方法，拟采用 ROOT TH1::Fit 的 "L" 选项（binned Poisson likelihood）。这是拟合目标函数的选择，gaus+pol1 是峰形模型，两者不是替代关系。各相关 bin 计数充分且模型适当时，Poisson 与 chi-square 拟合通常趋近；不能仅凭全谱条目多就断言本数据两者几乎相同。

相邻可辨峰可做多峰联合拟合，明显偏离基本峰形的谱段标记待复核。首版不加低能拖尾。

每个拟合的峰记录：参考能量、拟合峰心 (mean) 及误差、FWHM、拟合状态。弱峰误差不稳定时不能仅因 minimizer 收敛就判成功。

### 能量刻度与验证

采用二次多项式刻度：E(keV) = a0 + a1*A + a2*A^2，其中 A 为原始道址（Gaussian 拟合的 mean）。a0、a1、a2 的单位分别为 keV、keV/道址、keV/道址²；二次贡献须由数据验证。有效区间内检查 dE/dA = a1 + 2*a2*A > 0，不将回弯的曲线判为可用。

使用 ROOT TGraphErrors + pol2 拟合各峰的 (mean, E_ref) 对。峰心误差是横轴误差，单位为道址；参考能量误差是纵轴误差，单位为 keV，不得把峰心误差直接当作纵轴误差。通过 ROOT 的横轴误差处理或等价的有效方差传播：s_eff,i² = s_Eref,i² + (a1 + 2*a2*A_i)²*s_A,i²。未知参考能量误差明确标注未纳入；有联合峰拟合相关性时另作处理，不宣称独立误差公式适用。报告 a0、a1、a2 及不确定度、逐点能量残差和 chi2/ndf。

最好不少于 4 个可靠参考峰，并从低能区到高能区分散覆盖。pol2 有 3 个自由参数：少于 3 个不同峰位不足以约束；恰好 3 点可得到插值但 ndf=0，无法用残差拟合优度验证，须标记“验证点不足”；4 点也仅有 1 个剩余自由度，不能仅凭峰数判定可靠。保留候选结果与不足说明供用户判断，不把“最好不少于 4 个”改成一刀切的自动删除条件。

按教程常规检查残差的幅度、趋势及各峰质量，不添加无来源的统一 keV 阈值。报告所用参考峰的最低、最高能量和逐点分布；只在这些峰实际覆盖且分布合理的范围内评价刻度，不因点数足够就认可局部扎堆或源覆盖之外的外推。采用点数、能量跨度和低／中／高能覆盖共同判断，不通过调阈值追求全通道通过。

刻度能量残差定义为 ΔE_i = E_ref,i - (a0 + a1*mean_i + a2*mean_i²)，单位 keV。图内列出各点 (E_ref, ΔE)，以及 RMS = sqrt(sum(ΔE_i²)/N)、max|ΔE_i|；RMS 是描述量，不等同于系数不确定度或独立验证误差。chi2/ndf 使用已记录的误差处理；ndf=N-3，仅在 ndf>0 时给出比值，不能把 ndf=0 写成 0 或通过。

系统性的残差趋势用于判断模型是否充分。不允许为美化结果而删除数据点；有物理原因（峰形异常、合峰、匹配错误）的排除必须记录原因。

失败通道不输出伪成功系数，不自动套用邻道系数。LaBr3 若 pol2 无法可靠刻度则标记失败。

## PNG 布局

每个通道输出一张三面板 PNG，用于直观判断拟合效果和刻度质量：

```
+------------------------------------------+
|          上图：拟合能谱图                  |
|  完整道址谱 + 各峰 Gaussian+pol1 拟合曲线  |
|  标注已匹配峰的参考能量                    |
+---------------------+--------------------+
| 下左：峰拟合残差图    | 下右：刻度系数拟合图  |
| 各峰的 Pearson       | (mean, E_ref) 散点  |
| residual             | + pol2 拟合曲线     |
|                     | 图内标注：           |
|                     |  a0, a1, a2         |
|                     |  chi2/ndf           |
|                     |  各点 ΔE、RMS       |
|                     |  max|ΔE|、峰数、能区 |
+---------------------+--------------------+
```

- **上图**：该通道道址能谱，叠加各参考峰的局部 Gaussian+pol1 拟合曲线；在峰旁用统一编号标识参考能量与 mean，详细数值可放图内小表以免堆叠。默认对数纵坐标便于看到弱峰；显示范围和 PNG 尺寸须保证峰附近曲线可辨，不以平滑后的谱伪装实际拟合计数。
- **下左**：各能量峰局部拟合窗口内的 Pearson residual，r_j=(n_j-ν_j)/sqrt(ν_j)，无量纲；n_j 为 bin 计数，ν_j 为采用同一拟合定义计算的期望计数。按原道址排列并用峰编号区分，窗口间不连线、不计算未建模区域的残差，联合拟合窗口不重复计算。画零基线；ν_j<=0 时标记模型无效，不伪造残差。持续同向的结构提示检查峰形或本底，单个随机偏离不能直接证明模型错误。
- **下右**：刻度系数拟合图。横轴 mean（道址），纵轴 E_ref（keV），显示带误差的散点及 pol2 曲线。图内紧凑标注 a0、a1、a2 及误差、chi2/ndf、峰数、覆盖能区；另列各点的参考能量与 ΔE_i（keV），并给出 RMS、max|ΔE|。这些是刻度曲线的残差评估，不以左下峰形残差替代。保持三个子图，不额外加第四张残差子图；能量全量程上可能看不出小偏差，逐点 ΔE 数值用于明确定位。

同一峰编号在三个子图中保持一致，便于从偏离的刻度点回查对应的峰及残差。两类拟合的量分别标单位；不把能量峰 Poisson 拟合的目标函数值标成刻度曲线 chi2。峰拟合收敛、刻度曲线平滑都不能单独证明系数可用。
