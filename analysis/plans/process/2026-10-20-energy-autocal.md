## 目标与范围

制作可编译的 C++/ROOT 自动能量刻度程序，供当前 run 6082 和以后实验重复使用。默认发现并尝试拟合文件中的全部通道；用户可显式排除拟合，拟合完成后再决定是否采纳各通道系数。输出拟合参数 CSV、逐通道 PNG 回查图及包含拟合后直方图的 ROOT 文件。

程序首先处理单个解码 ROOT 文件，不默认增加多 run 合并、能量漂移修正、效率刻度、addback 或 gamma-gamma 符合矩阵制作。主要刻度对象是 HPGe / Clover 探测器，LaBr3 尝试拟合但不作为主要目标。

## 方法与统计处理

### 逐通道填谱

以每条解码记录为填谱单位，以 `(cid,sid,ch)` 为刻度单位；不使用时间符合筛选。只读取 cid、sid、ch、evte 四个分支，不对 pileup / outofr 做任何筛选。默认全部通道填谱，包括用户排除拟合的通道。

`evte` 完整整数取值范围为 0-65535。建议原始谱每整数道址一箱；寻峰可临时重分箱或平滑，但精细拟合回到未平滑计数谱。

峰的光滑程度与 bin 宽度密切相关。寻峰和峰形处理逻辑集中在一个 `.hh/.cc` 文件中（面向对象），负责：从直方图或数组中寻找可拟合的峰候选，提供合适的初始参数，判定峰拟合是否成功。

### 寻峰与自动匹配

候选峰搜索、粗刻度匹配、局部拟合和最终刻度分开处理。先用 ROOT 的 TSpectrum 寻峰，再按能量顺序和多条参考线的整体一致性搜索正斜率线性映射。参考网页方法：先由两个相距较远、指认可靠的强峰建立粗略线性关系，再据此定位其余参考线。增益与截距的合理搜索范围待由当前谱与电子学条件确定。

保留竞争匹配的歧义；缺峰、噪声峰、合峰、参考能量超出有效范围都允许存在。无法唯一确定映射时标记失败，不强行输出可用系数。

关于"两点锚定"：这是指当自动匹配失败时，用户可以为该通道手动指定两个已知峰位（道址, keV）作为初始猜测。用户已确认本程序是自动刻度，源数据来自 `sources.csv`；首版不实现手动锚定，匹配失败的通道直接标记失败。

自动拟合不要求每条源谱线都形成独立可辨峰。LaBr3 的相邻线可能合并，只有可辨且匹配可靠的峰用于刻度。

### 局部峰拟合

基本模型为 Gaussian + pol1（线性本底），即 f(x) = H*exp(-(x-mu)^2/(2*sigma^2)) + b0 + b1*(x-x0)。使用 ROOT 的 TH1::Fit，拟合选项包含 "L"（binned Poisson likelihood，参考网页的标准做法）。

关于 Poisson 似然：ROOT 的 "L" 选项使用 binned log-likelihood，对低统计量的 bin 比 chi-square 更稳定。对高统计量的谱两者结果几乎相同。这不改变 Gaussian+pol1 的模型本身，用户在 ROOT 中使用的 gaus+pol1 拟合峰获取 mean 的流程完全一致。

相邻可辨峰可做多峰联合拟合，明显偏离基本峰形的谱段标记待复核。首版不加低能拖尾。

每个拟合的峰记录：参考能量、拟合峰心 (mean) 及误差、FWHM、拟合状态。弱峰误差不稳定时不仅因 minimizer 收敛就判成功。

### 能量刻度与验证

采用二次多项式刻度：E(keV) = a0 + a1*A + a2*A^2，其中 A 为原始道址（Gaussian 拟合的 mean）。对 HPGe，a2 极小，效果近似线性。对 LaBr3，a2 可能较明显。

使用 ROOT TGraphErrors + pol2 拟合各峰的 (mean, E_ref) 对，峰心统计误差作为 y 方向误差。报告 a0、a1、a2 及不确定度、逐点残差。建议至少 4 条可靠且能量分布充分的峰才自动推荐，具体数量和残差阈值在实施中用数据确定。

系统性的残差趋势用于判断模型是否充分。关于"删点"：不能为了让拟合结果看起来好而人为删除残差较大的数据点再重新拟合。这是数据分析诚信的基本要求。如果某个点残差明显偏大，应检查该峰的拟合是否可靠（峰形异常、合峰、匹配错误等），有物理原因才能排除，且必须记录排除原因。

失败通道不输出伪成功系数，不自动套用邻道系数。LaBr3 若 pol2 无法可靠刻度则标记失败。

- 无排除配置时，当前输入应有 39 路拟合尝试记录；同一通道不得因树周期重复填谱。sid=8 必须在输出中。

- 重跑相同输入与配置得到一致的数值结果。
- 终端输出成功、失败、排除通道的统计。
