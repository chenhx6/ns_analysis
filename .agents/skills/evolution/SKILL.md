# 项目能力演进

来源：`analysis/third_party/muIon-beam/.codex/skills/evolution/SKILL.md`；来源版本见 `analysis/third_party/sources.lock.json`。本适配保留原技能的明确触发和增量采用原则，使用本项目目录与 Gitee 仓库。

出现相关能力缺口或演进任务时自动读取现有技能清单、失败记录和相关代码；提出与任务相关的候选。核对官方来源、固定提交、许可证、支持文件、依赖、安装脚本和适用边界，判断是新增、扩展、合并、仅供参考或不采用。

用户已指定仓库和采用范围时直接在该范围实施，避免重复询问。开放式发现请求先给出具体候选和采用建议，再按用户选择安装。下载缓存放在项目 `.runtime/` 或临时目录，持久技能维护于 `.agents/skills/` 并同步 OMX 的 `.codex/skills/`；证据与来源放入 `analysis/third_party/`。

验证实际能力后更新清单和项目约定，按用户授权同步到本项目远端。常规任务自动评估必要的能力改进并记录可复用经验；新工具采用仍限于任务已授权的范围。原始数据与 `../software/` 的目录边界始终适用。
