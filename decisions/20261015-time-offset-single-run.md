# 单 run 时间差谱与 ROOT 拟合

用户于 2026-10-15 要求在 `timeOffset/time_offset/` 重新编写最小 C++/ROOT 程序，参考 DecodeAndSortAll 风格和 event/sort.cc 的事件分组方法。旧目录仅保留参考，不删除。这是本轮新实现的方法记录，替代旧任务的多 run 分组、全候选滑窗及冻结验证交付要求；不是执行计划。

输入为 `decode_data/data_C2_6015_6015_wave.root`，cut 为 cid=0,1、sid=0..16，另验证 ch=0..15。不使用 CFD、能量门或旧偏移。继承用户已确定的参考 (0,2,5)、逐条 sr 换算时间（125/250 MHz 为 8 ns；100/500 MHz 为 10 ns）、差值 t_ref-t_channel；不复制外部程序的硬编码参考、符号和能量门。

按固定首条有效命中的时间分事件，跨度 1999 ns；Ge 每通道保留最后一条命中，CsI 保存每条命中，以模拟 sort.cc 的保存方式。参考为事件中最后一条参考命中，不自配对。输入倒序时关闭当前事件并重新开始，记录倒序数，不跨边界配对；这种分组会遗漏跨事件边界的近邻对，属于本轮指定方法的限制。

用户要求生成 2 ns 谱（1999 bins，[-1999,1999] ns）、24 ns 谱（166 bins，[-1992,1992] ns），用细谱评估峰形和拟合范围，在粗谱上用 ROOT 拟合单高斯+线性本底或双高斯+线性本底。ROOT 保存两种谱及拟合函数，文件名 time_offset_run.root；CSV 保存结果，报告解释验证及限制。

代理实现选择：细谱使用约 50 ns 移动平均抑制离散时钟格点，识别分离候选峰；候选触发双峰模型比较，同区间 Poisson 拟合，以 BIC 改善超过 10 支持双峰。阈值是实现启发式，非用户给定物理标准。双峰报告两分量，offset 暂选较高拟合峰中心并标记；不写原 crate 配置。弱峰、拟合失败或参数触边不提供可用 offset。用户以后可依据 ROOT 回查调整模型与范围。
